📋 TaskTracker - API для управления задачами
Современное приложение для управления задачами с высокой производительностью, построенное на FastAPI. Включает полный CRUD, JWT-аутентификацию, кеширование через Redis и контейнеризацию в Docker.

🚀 Возможности
✅ Полный CRUD - создание, чтение, обновление и удаление задач

🏷️ Категории - организация задач по пользовательским категориям

🔐 JWT-аутентификация - безопасная аутентификация и авторизация пользователей

⚡ Кеширование Redis - снижение нагрузки на БД на 15-20% благодаря умному кешированию

🐳 Готовность к Docker - контейнеризация с Docker Compose для быстрого развертывания

📊 Валидация данных - Pydantic-схемы для надежной валидации

🔄 Миграции БД - Alembic для версионного контроля схемы базы данных

📝 Логирование - логирование запросов и ответов для отладки и мониторинга

🛠️ Технологический стек
Бэкенд-фреймворк: FastAPI

База данных: PostgreSQL

ORM/Валидация: SQLAlchemy + Pydantic

Аутентификация: JWT (python-jose)

Кеширование: Redis (fastapi-cache)

Миграции: Alembic

Контейнеризация: Docker & Docker Compose

Сервер: Uvicorn
